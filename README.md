## 🚀 Обо мне / About Me
Я — увлеченный **Game Developer** и создатель интерактивных миров. Люблю участвовать в гейм-джемах, экспериментировать с игровой логикой, шейдерами и оптимизацией в Unity. Превращаю пиксели и строки кода в готовые геймплейные механики.

- 🏠 **Локация:** Работаю из дома (Working from home)
- 🏆 **Цель:** Создание запоминающихся инди-проектов с глубокой атмосферой
- ⚡ **Активность:** Постоянный участник Ludum Dare и разработчик на Itch.io
